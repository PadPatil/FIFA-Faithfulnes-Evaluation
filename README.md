# FIFA Faithfulness Evaluation

Reproducible notebooks and pipeline code for evaluating whether [**FIFA**](https://github.com/du-nlp-lab/FIFA) (Jing et al., 2026) — a fact-graph-based faithfulness metric originally proposed for text-to-image generation — can identify hallucinations in **VLM-generated descriptions of cinematic video**.

CSED 504 NLP project — Aeden Jameson, Padmanabh Patil.

This repository contains two parallel tracks: a notebook-driven exploration on BBC-style clips using open VLMs and structured extraction, and a fully packaged pipeline that runs end-to-end on synthetic video with mockable model backends.

| Subproject | Description |
|----------|-------------|
| [`bbc-faithful-eval/`](bbc-faithful-eval/) | Colab notebook (`CSED504_Faithful_Cuts.ipynb`) that generates descriptions with a Qwen-family VLM, extracts atomic facts, builds a Spatio-Temporal Semantic Dependency Graph, and scores faithfulness on cinematic video clips |
| [`FIFA_Eval_Pipeline_A1/`](FIFA_Eval_Pipeline_A1/) | Packaged `fifa_pipeline/` module covering sampling, VLM captioning, fact extraction, STSDG construction, VideoQA verification, FIFA scoring, controlled hallucination injection, and human-eval validation — runs headlessly with lightweight mock backends or real Qwen3-VL / Molmo 2 backends on GPU |

Each subproject has its own README with setup and run instructions.

## Run in Colab

Enable a **GPU runtime** before running. An G4 is recommended for the real VLM backends; a T4 works for the second notebook.

- **`CSED504_Faithful_Cuts.ipynb`** — VLM description generation + FIFA-style faithfulness scoring on BBC-style cinematic clips [![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/PadPatil/FIFA-Faithfulnes-Evaluation/blob/main/bbc-faithful-eval/CSED504_Faithful_Cuts.ipynb)

## Acknowledgements

This project builds on open research and tooling from:

- **FIFA** — fact-graph faithfulness metric this work adapts to video ([Jing et al., 2026](https://github.com/du-nlp-lab/FIFA))
- **Qwen3-VL / Qwen2.5-Omni** — VLM captioners used to generate video descriptions ([Alibaba Qwen Team](https://github.com/QwenLM))
- **Outlines** — structured JSON generation from LLMs used for fact extraction ([dottxt-ai/outlines](https://github.com/dottxt-ai/outlines))
- **NetworkX** — graph backbone for the Spatio-Temporal Semantic Dependency Graph
- **TIFA / TIFA160** — question-generation prior art for faithfulness evaluation ([Hu et al., ICCV 2023](https://arxiv.org/abs/2303.11897))
- **BBC Planet Earth dataset** — cinematic video source used for qualitative evaluation
